Nine dashes for a small screen

Nine installable themes for the display on my Nazaré, each with its own layout, not just its own colours. Every mockup below is drawn at true device size — 240 × 320 pixels — because a dash that only reads well when you blow it up is a dash that fails at 40 km/h. All nine render the same frame from the same board: 28 km/h, 43.2 V, 68 % of a 12s4p pack.

Nazaré

One theme that takes the single best idea from each of the others and throws away the rest. Speed dominates because it has to; the power-flow meter sits directly under it because on an eskate what you most want to feel is how hard you are pulling from the pack; everything else is grey until it isn't.

  1. Power flow, centre zero Regen left in cyan, drive right through amber. One glance, no number.
  2. Peripheral speed rail Climbs the left edge, so you read speed without looking at it.
  3. Ruthless hierarchy One dominant numeral. No unit label competing with it.
  4. Honest battery Segments, percentage and remaining range together — never just a bar.
  5. Restraint Two accents, both semantic. Everything else is graphite.
  6. Digits snap, gauges sweep The rail and the meter animate. The numbers never do.

Installing one

Themes are data, not code: a palette plus a layout name. The renderer already draws by region, so switching theme repaints once and then costs the same per frame as any other. 

make davega-theme THEME=nevera
  uploading themes/nevera.py -> /theme.py
  wrote /data/config.json: theme = "nevera"
  reboot to apply

Cost figures are estimates from each layout's redraw regions, not measurements — the only numbers measured on hardware are the four in the header. Names are my own; the lineage line credits the design language each treatment borrows from, and implies no affiliation with anybody.
